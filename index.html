プライバシーポリシー

最終更新日：2026年5月8日

本プライバシーポリシー（以下「本ポリシー」といいます。）は、TheaterRecords（以下「当アプリ」といいます。）の開発者（以下「当方」といいます。）が、当アプリにおいて取得または利用される情報の内容、利用目的および管理方法について定めるものです。当アプリをご利用いただく前に、本ポリシーをご確認ください。

第1条（収集する情報）

当アプリは、サービスの提供、品質向上、不具合解析および広告配信のため、当アプリ自身または当アプリが利用する外部サービスを通じて、以下の情報が取得される場合があります。

  • デバイス情報（端末モデル、OSバージョン等）
  • アプリの利用状況（起動回数、画面遷移等）
  • クラッシュログおよびエラーログ
  • IPアドレス
  • 広告識別子（IDFA。将来的にユーザーの許可を得たうえで取得する場合があります）

観劇記録、チケット情報、メモ等、ユーザーが入力したデータは、iCloud（CloudKit）を通じて、ユーザー自身の Apple ID に紐づく領域に保存および同期されます。当方は、通常、これらのデータの内容を直接閲覧または取得することはありません。

第2条（利用する外部サービス）

当アプリは以下の外部サービスを利用するものとし、各サービスが収集した情報は、各社のプライバシーポリシーに基づき管理されます。

Firebase AnalyticsGoogle LLC

アプリの利用状況および行動を分析するためのサービスです。デバイス情報、IPアドレス等が収集されます。
プライバシーポリシー

Firebase CrashlyticsGoogle LLC

クラッシュを検知および記録し、不具合の特定ならびに修正に利用するサービスです。スタックトレース、デバイス情報等が収集されます。
プライバシーポリシー

Google AdMobGoogle LLC

広告配信サービスです。端末情報および広告識別子を用いて広告を表示するものとします。プレミアムプラン購入後は広告は表示されません。
プライバシーポリシー

iCloud（CloudKit）Apple Inc.

ユーザーが入力した観劇記録等のデータを、ユーザー自身の iCloud アカウントを通じて複数デバイス間で同期およびバックアップするサービスです。当方はこれらのデータに直接アクセスすることはできません。
Apple プライバシーポリシー

第3条（利用目的）

当方は、収集した情報を以下の目的の範囲内において利用するものとします。

  • アプリの品質向上および機能改善のための利用状況分析（Firebase Analytics）
  • クラッシュ原因の特定および不具合修正（Firebase Crashlytics）
  • 最適化された広告の配信（Google AdMob）
  • 観劇記録データの複数デバイス間同期およびバックアップ（iCloud / CloudKit）

第4条（第三者提供）

当方は、収集した情報を、ユーザーの同意を得ることなく第三者に提供しないものとします。ただし、以下の各号に該当する場合はこの限りではありません。

  • 第2条に定める外部サービスへの送信（各社のプライバシーポリシーに基づき管理されます。）
  • 法令に基づく開示が必要な場合
  • 人の生命、身体または財産の保護のために必要であり、ユーザーの同意を得ることが困難な場合

第5条（オプトアウトについて）

ユーザーは、以下の方法により情報の収集を制限できるものとします。

  • 「設定」→「プライバシーとセキュリティ」→「トラッキング」から、当アプリによるトラッキングの許可を変更できます（iOS バージョンにより表示が異なる場合があります）。
  • 広告のパーソナライズに関する設定は、Google の広告設定から変更できる場合があります。
  • iCloud 同期を無効化するには、iOS の設定から Apple ID → iCloud を開き、TheaterRecords の同期をオフにしてください。詳細は Apple サポート をご参照ください。

第6条（個人情報に関する権利）

ユーザーは、当方が法令上保有する個人情報に該当する情報について、個人情報の保護に関する法律その他の適用法令に基づき、利用目的の通知、開示、訂正、追加、削除、利用停止、消去または第三者提供の停止を請求できる場合があります。

請求は第10条に定めるお問い合わせ先までメールにてお申し出ください。ご本人確認のうえ、合理的な期間内に対応するものとします。なお、適用法令に基づき対応が困難な場合は、その旨をお伝えします。

当アプリが利用する外部サービス（Firebase、Google AdMob 等）が収集する情報については、各社のプライバシーポリシーに従い、各社に直接ご請求ください。

第7条（セキュリティ）

当方は、収集した情報の不正アクセス、改ざんおよび漏えいを防止するため、合理的な安全管理措置を講じるものとします。ただし、インターネット上の通信において完全な安全性を保証するものではありません。
